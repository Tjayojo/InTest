# InTest.Runtime

Runtime support for MSTest projects generated by
[`InTest.Cli`](https://www.nuget.org/packages/InTest.Cli) — the base class, fixture handling,
and identity/auth plumbing the generated test classes call into at run time.

You don't reference this package by hand: `intest init` adds it to the generated project's
`.csproj` automatically, pinned to a version compatible with the CLI that generated the project.

Full documentation, including the compatibility contract between `InTest.Cli` and
`InTest.Runtime`, lives in the [InTest repository](https://github.com/Tjayojo/intest) — start
with [`docs/getting-started.md`](https://github.com/Tjayojo/intest/blob/main/docs/getting-started.md).
