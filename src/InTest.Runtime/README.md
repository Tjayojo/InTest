# InTest.Runtime

Framework-neutral runtime support for API integration tests generated by
[`InTest.Cli`](https://www.nuget.org/packages/InTest.Cli): fixture handling, schema validation,
and identity/auth plumbing that a test-framework adapter package delegates to at run time. This
package names no test framework and pulls in none — nothing here references MSTest, xUnit, or
NUnit.

You don't reference this package directly. An MSTest project references
[`InTest.Runtime.MSTest`](https://www.nuget.org/packages/InTest.Runtime.MSTest) instead, which
brings this package in transitively along with the MSTest-specific `TestHost` and `ApiTestBase`
types a generated project's test classes actually call into. `intest init` adds the adapter
package to the generated project's `.csproj` automatically, pinned to a version compatible with
the CLI that generated the project. xUnit and NUnit adapters are not shipped yet.

Full documentation, including the compatibility contract between `InTest.Cli` and the runtime
packages, lives in the [InTest repository](https://github.com/Tjayojo/intest) — start
with [`docs/getting-started.md`](https://github.com/Tjayojo/intest/blob/main/docs/getting-started.md).
